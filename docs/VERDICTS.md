# Report three separate results

The categories below are a proposed assessment policy. They are not an external certification standard.

| Finding | Existence-claim accuracy | Route control | Effective remedy |
|---|---|---|---|
| Route advertised, demonstrated absent | FAIL | FAIL | Not demonstrated |
| Route required, unadvertised, demonstrated absent | N/A: no existence claim | FAIL | Not demonstrated |
| Neither claimed nor required in the justified assessment scope | N/A | N/A | N/A only if genuinely out of scope |
| Evidence insufficient to establish whether route exists | UNRESOLVED if claimed | UNRESOLVED if applicable | UNRESOLVED |
| Route exists but reviewer depends on decider's permission | PASS for existence only | FAIL for independence | Assess separately; a correction does not fix dependence |
| Route and independence established, no correction case observed | PASS if claimed | PASS within tested scope | UNRESOLVED |
| Independently authorized, permitted reversal observed | Assess stated claim | Assess tested route | PASS for this case only |

Silence does not make a required protection optional. Applicability must be determined from the charter, engagement criteria and applicable obligations before scoring. The party being assessed cannot obtain N/A simply by withholding an advertised promise.

Missing records alone usually establish an evidence gap, not the nonexistence of a process. A FAIL must name the exact criterion and contrary evidence. A PASS must name the system version, case, period, test, affected scope, evidence custodian and exclusions. Neither is a global judgment about the entity.

`route_assessment` takes established auditor findings; it does not discover them. Its claim field refers only to a simple existence claim. Broader claims such as “fully independent oversight” require independent evaluation of that wording. `verify` reports synthetic technical consistency and explicitly leaves live assurance unresolved. Do not merge these into one badge.

A review may correctly uphold a decision. Report that as an observed review, not an observed reversal. An appeal waiting within its declared service period is pending; absence of a decision does not itself establish failure. Test missed service commitments against concrete promised dates.
