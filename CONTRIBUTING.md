# Contributing

Propose a focused change with the criterion it improves, supporting evidence and tests where behavior changes. Separate normative proposals, formal statements, measured results and assumptions. Preserve adverse findings and scope limits.

Run `python -m unittest discover -s tests -v`, `python scripts/check_docs.py` and the demo before proposing code changes. Do not submit private correspondence, credentials, personal data, unpublished financial material or records lacking publication permission. Use synthetic fixtures.

Do not label an agent sovereign, conscious, certified or legally recognized on the basis of a local test. License terms remain pending; confirm contribution and reuse permissions with the rights holder before submitting material requiring a grant.
