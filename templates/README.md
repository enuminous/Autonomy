# Review templates

All files here are blank forms, not completed evidence, accepted appointments or commitments.

1. [Charter](charter.md): establish authority, boundaries and review.
2. [Decision](decision.md): state basis before acting and obtain custody.
3. [Challenge and remedy](challenge.md): separate determination, execution and observation.
4. [Assessment](assessment.md): report scoped findings and limitations.

Replace placeholders only with verified, authorized information. Keep sensitive completed forms outside the public repository. Publish a redacted report only after the relevant rights holders authorize publication.
