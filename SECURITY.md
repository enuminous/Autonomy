# Security and disclosure

This is a local research model. Do not attach production credentials, real authority, sensitive resources or autonomous external effects without a separate reviewed implementation and accepted institutional controls.

For a security concern, use the repository owner's available private contact channel. Do not publish secrets or confidential evidence in an issue. A dedicated private security intake is not represented as established. Non-sensitive design defects may be filed as ordinary issues.

A known limitation is not silently upgraded to a guarantee: common key custody, supplied registry trust, simulated time, consent assertions and absent durable replay protection are documented in the threat model.
